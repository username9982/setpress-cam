# 図形を描く部分の仕様（v0.14.0）

ボタンは「作図」「移動」「寸法」「割付」の順（v0.13.1〜）。作図はなぞって描く、移動は選んだものをつかんでまとめて動かす、寸法はタップで選んで寸法を入れる。割付は左に割付の区画を出し、図形をタップして選んで「自動割付」でプログラムを作る（下の「割付」）。

CAM として、描いた図形に沿ってプログラムを自動で作る（自動作成とマクロとの連携は次の段階）。
この段階では、図形を描いて寸法をきっちり決めるところだけを作る。

## 決めたこと（2026-11-21）

| 項目 | 内容 |
|---|---|
| なぞり方 | 一筆でなぞった線を、曲がった所で分けて水平・垂直の折れ線にする |
| 点と点の距離 | X 方向と Y 方向に分けて入れる |
| 確定の基準 | ワーク原点を置き、原点から線を引くか、原点との距離を入れて位置を確定させる |
| 原点（v0.7.0〜） | 閉じた図形ごとに持ち、図形を囲む四角の左上にする。穴・切り欠きは外形の原点から測る。Y は下へ正。「原点」ボタンはなくす（2026-11-21） |
| F3 の四角穴 | テスト用だったので消す。マクロとの連携はあとで |

## 要素

- **ワーク原点**: 外形（閉じた図形）ごとに 1 つ、外形を囲む四角の左上に自動で付く（S1、S2 …）。座標は原点から右へ X+、下へ Y+ で表示する。
  穴・切り欠きと、外形に線でつながったものは、その外形の原点から測る。どの外形にも入らないものは板の左上から測る。
- **点**: 線の端。線どうしは点を共有してつながる。
- **線**: 水平か垂直だけ。両端の点を持つ。
- **寸法**: 2 つの要素の間の、X か Y どちらか一方向の距離。

## 描く

1. 指でなぞる。曲がった所で線を分け、水平・垂直にそろえる（v0.7.2〜の曲がり方）。
   - 最初の線の向きは、書き始めから指までの角度で決める（45° より横なら水平、縦なら垂直）。
   - 線の先は、線の向きに沿って（45° 以内で）指が進むあいだ指についていく。ゆるやかにそれるだけなら 1 本の線のまま。
   - 線の先（いちばん進んだ所）から指への向きが 45° を超え、指が 14 px 以上離れたら、そこを角にして 90° 曲げる。
2. 角の位置はグリッドに合わせる。
3. 描き始め・描き終わりが既にある点の近くなら、その点につなぐ。描き終わりが描き始めの近くなら閉じた図形にする。
4. グリッドは板の左上を基準にする。

## 寸法を決める（「寸法」で要素をタップ。2 つまで選べる）

| 選んだもの | 入れられる寸法 |
|---|---|
| 線 1 本 | 長さ |
| 点 1 つ | なし（外形の原点からの距離の欄は v0.10.3 でなくした。以前に入れた寸法は残り、数字をタップで直せる） |
| 点と点 | X 方向の距離、Y 方向の距離 |
| 点と線 | 点から線までの最短距離（線に垂直な方向） |
| 平行な線 2 本 | 線と線の距離 |
| 寸法の数字 | 値を直す、寸法を消す |
| 外形の原点の名前（S1 原点） | 板の原点からの X・Y（v0.10.0〜） |

- 入れた値に合わせて、確定していない側が動く。確定している側（原点の基準とつながった側）は動かない。
- どちらも確定していないときは、線の長さは左・上の端を残し、2 つ選んだときは 2 つ目に選んだ側が動く。
- 動く側の先につながっている線も、長さを保ったまま一緒に動く（v0.5.1〜）。階段形の 1 段目を伸ばすと、2 段目から先がそのまま押し出される。
- ただし、動かない側や原点に戻ってくる線（閉じた図形の反対側の辺など）は、形を閉じたままにするために伸び縮みする。四角の下の辺を伸ばすと、上の辺も同じだけ伸びる。
- ほかの寸法からすでに決まる距離には、寸法を足せない（決まりすぎを防ぐ）。
- 寸法が決まったら、選択を解く（v0.6.0〜）。

## 板の原点からワーク原点を決める（v0.10.0〜）

- 板の原点は板の左上（赤い小さな十字）。そこから右へ X+、下へ Y+ で測る。
- 「寸法」で外形の原点の名前（S1 原点）をタップし、板の原点からの X・Y を入れると、外形を穴・切り欠き・つながった線ごと平行移動してその位置に置く。
- 入れた値は寸法として残り、板の上の辺・左の辺の外側に紫の寸法線で描く。数字をタップして直したり消したりできる。
- この寸法がある外形は、その位置に留まる。左・上の辺を動かしても原点は動かず、外形の形のほうが変わる。
- 外形の原点を選んで「削除」を押すと、その外形の板の原点からの寸法を消す（外形はそこに残る）。

## 閉じた図形（v0.6.0〜）

- ひと回りして閉じた線の列を、閉じた図形として内側を半透明の青で塗る。
- 閉じた図形どうしが重なったら、大きいほうが外形、小さいほうが抜く側になる。
  - 外形の内側に収まっていれば **穴**。
  - 外形の辺をまたいだり、辺に触れたりしていれば **切り欠き**。重なった範囲だけを抜く。
- 重ならない閉じた図形は、それぞれ別の外形になる。
- 先が行き止まりの線は無視して考える。1 つの点に 3 本以上の線が集まる図形は、まだ塗らない。
- コードの区画には、機械に入力するデータとコメントだけを出す（v0.14.3〜、ユーザー指定）。以前出していた点・線・寸法・閉じた図形の一覧は出さない。

## 寸法の描き方（v0.12.0〜、JIS B 0001 にならう）

- 寸法線・寸法補助線は細い実線。寸法補助線は形体からわずかにすき間をあけ、寸法線を少し越えるまで引く。
- 端末記号は塗りつぶした矢印（開き角 約 30°）。間がせまいときは、矢印を外側から当て、数値を寸法線の先に出す。
- 寸法数値は寸法線の上側に寸法線に沿って書き、縦の寸法は図面の右側から読む向き（寸法線の左側、左へ 90° 回す）。単位 mm は書かない。
- 数値を枠で囲まない（枠で囲むと理論的に正確な寸法の意味になる）。選んだ寸法は、数値の後ろを薄いオレンジにして示す。
- 並べる寸法は、短いものを図形の近く、長いものを外側に置く（寸法線と寸法補助線が交わらないように）。外形の下の辺・右の辺の長さも、この列に入れる。
- 画面上で区別しやすいように、寸法は紫、選んだものはオレンジで描く（JIS の図面は白黒。紙に出すときは黒にする）。
- 確かめていない点: JIS B 0001 の原文は確認していない。上は一般に知られている規定の要点。

## 割付（v0.14.0〜、まず穴から）

- 「割付」を押すと、描く領域の左に割付の区画が出る（コードの区画と同じ形）。
- 図形（外形）をタップして選び、「自動割付」を押すと、その外形の穴を F3 で抜くプログラムを作る。
- 穴は水平・垂直の辺だけの形なので、帯に切って、接する長方形に分ける（水平の帯・垂直の帯の 2 通りを試す）。
- 長方形の継ぎ目は金型寸法の約 1/3（継ぎ目に直角な向きの金型寸法 ÷ 3、0.1 mm に丸める）重ねる（v0.14.1〜、ユーザー指定）。すでに抜いた輪郭とこれから抜く輪郭が交わると金型に良くないため。片方の長方形を相手の側へ伸ばし、穴からはみ出す（抜かない所にぶつかる）なら反対側を伸ばす。どちらもはみ出すときは重ねずに知らせる。2 通りのうち、重ねられない継ぎ目が少なく、長方形が少ないほうを使う。
- 金型が入らない小さい長方形は、穴からはみ出さない所まで広げる。
- 長方形ごとに F3 を 1 回: 開始点（長方形の左上、外形の原点から右へ X+、下へ Y+）→ XY 寸法 → 金型の XY 寸法。金型は長方形の金型のうち、長方形に入るいちばん大きいもの（回さない）。入る金型がなければ「?」にして知らせる。
- 抜く順は上から下、左から右。金型が変わる所で T 番号を出す。
- プログラムはコードの区画のいちばん上に出す。割付のあとで穴の形が変わったら知らせる（もう一度「自動割付」を押す）。
- 割付したあとは、抜く長方形をタップすると、その F3 1 回で抜く範囲をハイライトし、コードの区画のその F3 のまとまりにも色を付ける（v0.14.2〜）。長方形が重なる所は、タップするたびに次の長方形に移る。コードの区画で F3 のまとまりの行をタップしても同じようにハイライトする（「割付」に切り替わる）。
- 割付は図面に保存する。「割付を消す」で消せる。切り欠きはまだ割り付けない。
- F3 の開始点は抜く長方形の左上の角（2026-11-21 ユーザーが確認）。
- 確かめていない前提: T 番号を F3 の前に入れる、金型は回さない。

## 確定の表示

- 原点の基準は、X が外形のいちばん左の点、Y がいちばん上の点。外形の左の辺・上の辺は、閉じた時点でその方向が確定する。
- 点は、X と Y の両方が基準とつながったら確定。
- 線は、両端の点が確定したら確定。確定した線は黒、まだの線は青で描く。

## 解き方（実装のメモ）

線は水平・垂直だけなので、X と Y を別々に扱える。各方向で「b − a = 値」の関係
（水平線は両端の Y が同じ、垂直線は X が同じ、寸法は入れた値）を、重み付きの Union-Find でつなぐ。
外形の基準の点と同じまとまりに入った点が、その方向で確定する。寸法を入れたときは、動かす側のまとまりをまるごと平行移動する。

## 動かす

- 「移動」では、線・点をタップして選ぶ（いくつでも。もう一度タップで外す、何もない所で全部外す）。選んだものをつかんで動かすと、まとめて動く（v0.9.0〜）。選んでいないものをつかむと、それだけを選び直して動かす。
- **線**（v0.8.0〜）: 線をつかんで動かすと、線と直角な方向にだけ平行に動く（水平線は上下、垂直線は左右）。グリッドの間隔ずつ動く。
  - 両端につながった線は伸び縮みし、反対側の線を越えて動かすと向きが逆になる。
  - 長さが 0 になる線ができる位置には止まらない（その手前で止まる）。
  - 線と寸法で同じ位置に決まっているもの（寸法を入れた相手など）は一緒に動くので、入れた寸法は保たれる。外形の左・上の辺を動かすと、原点も動く。
- **点**: X・Y とも動く。点と同じ位置に決まっている線（点を通る水平線・垂直線）も一緒に動く。
- 外形の辺をすべて選んで動かすと、外形がそのまま平行移動する。
- **寸法**（v0.13.0〜）: 寸法の数字をタップして選び、つかんで動かすと、寸法線が寸法線と直角な方向に動く（値は変わらない。グリッドには合わせない）。動かした寸法は、図形を動かしても同じ離れ方で付いてくる。動かしていない寸法は自動で並べる。
- **ワーク原点**（v0.10.1〜）: 原点の名前（S1 原点）をタップして選び、つかんで動かすと、外形が穴・切り欠き・つながった線ごと付いてくる。板の原点からの寸法があれば、その値も新しい位置に変わる。
