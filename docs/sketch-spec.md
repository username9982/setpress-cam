# 図形を描く部分の仕様（v0.7.0）

CAM として、描いた図形に沿ってプログラムを自動で作る（自動作成とマクロとの連携は次の段階）。
この段階では、図形を描いて寸法をきっちり決めるところだけを作る。

## 決めたこと（2026-11-21）

| 項目 | 内容 |
|---|---|
| なぞり方 | 一筆でなぞった線を、曲がった所で分けて水平・垂直の折れ線にする |
| 点と点の距離 | X 方向と Y 方向に分けて入れる |
| 確定の基準 | ワーク原点を置き、原点から線を引くか、原点との距離を入れて位置を確定させる |
| 原点（v0.7.0〜） | 閉じた図形ごとに持ち、図形を囲む四角の左上にする。穴・切り欠きは外形の原点から測る。Y は下へ正。「原点」ボタンはなくす（2026-11-21） |
| F3 の四角穴 | テスト用だったので消す。マクロとの連携はあとで |

## 要素

- **ワーク原点**: 外形（閉じた図形）ごとに 1 つ、外形を囲む四角の左上に自動で付く（S1、S2 …）。座標は原点から右へ X+、下へ Y+ で表示する。
  穴・切り欠きと、外形に線でつながったものは、その外形の原点から測る。どの外形にも入らないものは板の左上から測る。
- **点**: 線の端。線どうしは点を共有してつながる。
- **線**: 水平か垂直だけ。両端の点を持つ。
- **寸法**: 2 つの要素の間の、X か Y どちらか一方向の距離。

## 描く

1. 指でなぞる。曲がった所で線を分け、水平・垂直にそろえる（v0.7.2〜の曲がり方）。
   - 最初の線の向きは、書き始めから指までの角度で決める（45° より横なら水平、縦なら垂直）。
   - 線の先は、線の向きに沿って（45° 以内で）指が進むあいだ指についていく。ゆるやかにそれるだけなら 1 本の線のまま。
   - 線の先（いちばん進んだ所）から指への向きが 45° を超え、指が 14 px 以上離れたら、そこを角にして 90° 曲げる。
2. 角の位置はグリッドに合わせる。
3. 描き始め・描き終わりが既にある点の近くなら、その点につなぐ。描き終わりが描き始めの近くなら閉じた図形にする。
4. グリッドは板の左上を基準にする。

## 寸法を決める（「選ぶ」で要素をタップ。2 つまで選べる）

| 選んだもの | 入れられる寸法 |
|---|---|
| 線 1 本 | 長さ、外形の原点からの距離（水平線は Y、垂直線は X） |
| 点 1 つ | 外形の原点からの X・Y |
| 点と点 | X 方向の距離、Y 方向の距離 |
| 点と線 | 点から線までの最短距離（線に垂直な方向） |
| 平行な線 2 本 | 線と線の距離 |
| 寸法の数字 | 値を直す、寸法を消す |

- 入れた値に合わせて、確定していない側が動く。確定している側（原点の基準とつながった側）は動かない。
- どちらも確定していないときは、線の長さは左・上の端を残し、2 つ選んだときは 2 つ目に選んだ側が動く。
- 動く側の先につながっている線も、長さを保ったまま一緒に動く（v0.5.1〜）。階段形の 1 段目を伸ばすと、2 段目から先がそのまま押し出される。
- ただし、動かない側や原点に戻ってくる線（閉じた図形の反対側の辺など）は、形を閉じたままにするために伸び縮みする。四角の下の辺を伸ばすと、上の辺も同じだけ伸びる。
- ほかの寸法からすでに決まる距離には、寸法を足せない（決まりすぎを防ぐ）。
- 寸法が決まったら、選択を解く（v0.6.0〜）。

## 閉じた図形（v0.6.0〜）

- ひと回りして閉じた線の列を、閉じた図形として内側を半透明の青で塗る。
- 閉じた図形どうしが重なったら、大きいほうが外形、小さいほうが抜く側になる。
  - 外形の内側に収まっていれば **穴**。
  - 外形の辺をまたいだり、辺に触れたりしていれば **切り欠き**。重なった範囲だけを抜く。
- 重ならない閉じた図形は、それぞれ別の外形になる。
- 先が行き止まりの線は無視して考える。1 つの点に 3 本以上の線が集まる図形は、まだ塗らない。
- 図形データの区画に「; 閉じた図形」として、外形・穴・切り欠きと、その範囲を並べる。

## 確定の表示

- 原点の基準は、X が外形のいちばん左の点、Y がいちばん上の点。外形の左の辺・上の辺は、閉じた時点でその方向が確定する。
- 点は、X と Y の両方が基準とつながったら確定。
- 線は、両端の点が確定したら確定。確定した線は黒、まだの線は青で描く。

## 解き方（実装のメモ）

線は水平・垂直だけなので、X と Y を別々に扱える。各方向で「b − a = 値」の関係
（水平線は両端の Y が同じ、垂直線は X が同じ、寸法は入れた値）を、重み付きの Union-Find でつなぐ。
外形の基準の点と同じまとまりに入った点が、その方向で確定する。寸法を入れたときは、動かす側のまとまりをまるごと平行移動する。

## 動かす

- 点や線を指で動かせる。基準とつながった方向には動かない。
- X・Y とも確定した点（外形の左上の角など）をつかむと、外形を穴・切り欠きごとまるごと動かす。
