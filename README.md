# セットプレス CAM（iPad 用 Web アプリ）

iPad で使う、セットプレス向けの CAM。古い機械で、操作盤に数値を対話式に手入力してデータを作るため、最終的には「手で打ち込むための数値」を画面に表示する。

## いまの段階（v0.17.7・図形を描く部分と割付）

描いた図形に沿ってプログラムを自動で作る CAM にするため、まず図形を描いて寸法をきっちり決める部分を作っている。
仕様は [docs/sketch-spec.md](docs/sketch-spec.md)。プログラムの自動作成とマクロ（F3 など）との連携は次の段階。

- **ワーク原点**: 閉じた図形（外形）ごとに、図形を囲む四角の左上に自動で付く。座標は原点から右へ X+、下へ Y+。穴・切り欠きは外形の原点から測る
- **作図**: 指でなぞると、曲がった所で分けて水平・垂直の折れ線にする。角はグリッドに合わせる。既にある点の近くから描き始める・描き終えるとつながり、描き始めに戻ると閉じた図形になる
- **寸法**: 線・点・寸法の数字をタップして選ぶ（2 つまで）。右上の欄に数字を入れて寸法を決める。選んだものは「削除」で消せる
  - 線 1 本: 長さ
  - 点と点: X 方向・Y 方向の距離
  - 点と線: 最短距離
  - 平行な線 2 本: 線の間の距離
  - 寸法の数字: 値を直す、寸法を消す
  - 外形の原点の名前（S1 原点）: 板の原点（板の左上）からの X・Y。外形ごとその位置に動き、留まる
  - 寸法が決まると選択を解く
- 閉じた図形の内側を半透明で塗る。重ねた小さい図形は、内側に収まれば穴、辺をまたげば切り欠きとして、重なった範囲を抜く
- 寸法は JIS B 0001 の描き方にならう（細い実線、塗りつぶし矢印、数値は寸法線の上・縦は右から読む向き、枠なし、短い寸法を内側）
- **割付**: 左に割付の区画を出す。図形をタップして選び「自動割付」で、穴を長方形に分けて F3（開始点 左上 → XY 寸法 → 金型 XY 寸法）で抜くプログラムを作り、コードの区画のいちばん上に出す。金型は長方形の金型のうち入るいちばん大きいもの。長方形の継ぎ目は、抜かない所にぶつからなければ金型寸法の約 1/3 重ねる。抜く長方形やコードの F3 のまとまりをタップすると、その F3 1 回で抜く範囲をハイライトする。切り欠きは単発か F3 で、外形の外へ F13 の金型寸法の約 1/3 広げて抜く（ほかのワークにぶつかるときは広げない）。L 字のような外形は、囲む四角から欠けた所も切り欠きとして抜く。最後に外形を囲む四角を F13（開始点 → 外形 XY → 金型 XY → 角 R、金型寸法のぶん外側にオフセット）で輪郭を抜く。割付の区画でミクロジョイント（図面に保存し、割り付け直しても同じ値）を入れると、角 R を 金型寸法 + ミクロジョイント にして角を少しつなげたままにする（長方形の金型では、短いほうの辺の余りを F13 の前に単発で抜き、F13 の帯と約 1/3 重ねる。単発は金型の中心の座標）。割付はワークを動かすと一緒に動く。割り付けたワークごとに、F3・F13 などを F100（2 つ目のマクロは F101…）と F110 で囲んでマクロに登録し（中の行は 1 段下げる）、そのあとに F23（マクロ番号 → 板の原点（左上）からワーク原点までの XY → ピッチ XY（抜く形を囲む四角の寸法 + 10 mm、多数個取りの間隔）→ 列数 XY（いまは 1 と 1））を出す。マクロの中には T 番号を書けないので、T はマクロの前に出し、ワークの途中で金型が変わるときはそこでマクロを分けて、それぞれ F23 で同じ位置に配置する。
- **下の帯**: バージョンのすぐ左に、選んだ点の絶対座標（板の左上から）か、選んだ線の長さを出す。切り欠きはまだ
- 外形の原点とつながって位置が決まった線は黒、まだ動く線は青で描く
- **移動**: 線・点をタップして選び（いくつでも）、つかんでまとめて動かす。線は平行に動き、両端につながった線は伸び縮みし、越えると向きが逆になる（入れた寸法は保つ）。外形の辺をすべて選ぶか、ワーク原点の名前（S1 原点）をつかめば外形ごと動く。寸法の数字をつかむと寸法線の位置を動かせる。何もない所からなぞると四角の枠で選べる（枠にすっぽり入る線を選び、外形がまるごと入ればその外形の原点を選んで外形ごと動かす。いまの選択に足す）
- 指2本で拡大縮小・移動、「全体表示」で元に戻す。元に戻す、削除、板の大きさと板厚（「板 幅 × 高さ × t 厚さ mm」。板厚は 0.1〜50 mm、空なら未設定）の変更
- 「元に戻す」の履歴は作業中の図面と一緒に自動保存し、再読み込みしても最初まで戻せる（2000 回・200 万文字まで。超えたら古いものから消す。別の図面を開く・新規作成すると履歴は消える）
- 新規作成のとき、プログラム番号と金型 T1〜T3 を決める。あとから「金型」で直せる
- 右側（縦向きでは下側）のコードの区画には、機械に入力するデータ（プログラム番号・割付の F3・マクロの登録 F100〜F110・配置の F23）とコメントだけを出す（v0.14.3〜。点・線・寸法の一覧は出さない）
- 名前を付けて保存・開く、JSON ファイルへの書き出し・読み込み、作業中の図面の自動保存
- オフラインで動く PWA（ホーム画面に追加して使う）

v0.4.0 までの四角穴（F3）はテスト用だったので消した。そのころ保存した図面を開くと、四角穴は読み込まれない。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` / `app.js` | アプリ本体（ビルド不要の素の HTML・JavaScript） |
| `geom.js` | 点・線・寸法のデータと、寸法から位置を決める処理 |
| `docs/sketch-spec.md` | 図形を描く部分の仕様 |
| `manifest.webmanifest` | PWA の設定（名前・アイコン） |
| `sw.js` | オフライン用の Service Worker |
| `icons/` | アイコン（`tools/make_icons.py` で作る） |
| `tools/make_icons.py` | アイコンを作る開発用の道具（Python 標準ライブラリのみ） |
| `windows/SetPressCam/` | Windows 版（C#、.NET 10、WinForms）。`Geom.cs` は `geom.js`、`Editor*.cs` は `app.js` の処理を移したもの |
| `windows/setpresscam.iss` / `windows/build_win.py` | Windows 版のインストーラー（Inno Setup）と、それを作る開発用の道具 |
| `windows/tests/make_cases.py` | Windows 版と Web 版の割付が同じか確かめる図面を作る開発用の道具 |

## PC で動かす

```
python -m http.server 8765 --bind 127.0.0.1
```

ブラウザで http://localhost:8765 を開く。

## iPad で使う

公開先: https://username9982.github.io/setpress-cam/ （GitHub Pages。`main` ブランチに push すると数分で更新される）

Service Worker（オフライン動作）は **HTTPS** でしか動かないため、HTTPS の場所に置く必要がある。

1. iPad の Safari でページを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから開く（一度開けば、ネットが無くても動く）

保存した図面は、そのホーム画面のアプリの中に残る。Safari で開いたページとホーム画面のアプリでは保存場所が別になる。念のため「開く」→「ファイルに書き出す」でバックアップを取る。

## Windows で使う

Web 版と同じ仕様・同じ画面（ツールバー、割付・コードの区画、ダイアログ）・同じ図面ファイル（「ファイルに書き出す」の JSON）で動く Windows 版がある。版の番号も Web 版とそろえる。メニューバーは無い。

- Web 版の「開く」→「Windows 版をダウンロード」（いちばん新しいリリースのインストーラーへ直接つなぐ。取れないときはリリースのページを開く）か、[Releases](https://github.com/username9982/setpress-cam/releases) から `SetPressCam-<版>-setup.exe` を取って実行して入れる（管理者権限は要らない。.NET 10 が入っていない PC では、同梱の .NET 10 デスクトップ ランタイムを入れるときだけ Windows の確認が出る）
- マウスの左ボタンで描く・選ぶ・動かす。右ボタンか中ボタンのドラッグで画面を動かし、ホイールで拡大縮小。Ctrl+1〜4 でモード、Ctrl+Z で元に戻す、Del で削除、Home で全体表示
- Ctrl+N で新規、Ctrl+O で開く、Ctrl+S で保存
- 「保存」「開く」は Web 版と同じく、図面に名前を付けてアプリの中（`%APPDATA%\SetPressCam\drawings.json`）にしまう。「開く」の「ファイルから読み込む」「ファイルに書き出す」で、Web 版と同じ形の JSON ファイルとやりとりする
- 作業中の図面・元に戻す履歴・設定も `%APPDATA%\SetPressCam` に自動保存し、次に起動したとき続きから使える
- 起動のとき（と「開く」→「更新の確認」、下の帯の版の番号をクリック）、GitHub Releases に新しい版があれば知らせる。「更新する」でインストーラーをダウンロードし（大きさと SHA-256 を確かめる）、画面を出さずに入れて起動し直す。「起動したときに新しい版を確かめる」で切れる
- 画面は日本語だけ

作り方（作る PC に .NET 10 SDK と Inno Setup 6 が要る。`windows/third_party/` に .NET 10 デスクトップ ランタイムのインストーラーを置く。`build_win.py` の RUNTIME_URL から取る。git には入れない）:

```
python windows/build_win.py
```

`windows/build/output/SetPressCam-<版>-setup.exe` ができる。これを GitHub Releases に付けて公開する（タグは `v<版>`）と、入っているアプリが更新を見つける。

```
gh release create v0.17.6 windows/build/output/SetPressCam-0.17.6-setup.exe --title "v0.17.6"
```

## 更新するとき

中身を変えたら、版を上げる。

```
python tools/bump_version.py 0.2.1
```

`app.js` の `APP_VERSION`、`sw.js` の `CACHE_NAME`、`index.html` の `style.css?v=` / `geom.js?v=` / `app.js?v=`、Windows 版の版（`Program.cs`、`SetPressCam.csproj`、`build_win.py`）をまとめて書き換える。
割付やコードの作り方を変えたときは、Windows 版の `Geom.cs` / `Editor*.cs` にも同じ変更を入れ、`windows/tests/README.md` の手順で結果が同じか確かめる。
URL に版を付けるのは、更新の直後に新しい `index.html` と古い `style.css`（キャッシュに残ったもの）が組み合わさって画面が崩れるのを防ぐため（v0.2.0 で、描く領域が消えた）。
Service Worker はネットにつながっていれば新しいファイルを取り、つながっていなければ前に取ったファイルで動く。
