# セットプレス CAM（iPad 用 Web アプリ）

iPad で使う、セットプレス向けの CAM。古い機械で、操作盤に数値を対話式に手入力してデータを作るため、最終的には「手で打ち込むための数値」を画面に表示する。

## いまの段階（v0.8.0・図形を描く部分）

描いた図形に沿ってプログラムを自動で作る CAM にするため、まず図形を描いて寸法をきっちり決める部分を作っている。
仕様は [docs/sketch-spec.md](docs/sketch-spec.md)。プログラムの自動作成とマクロ（F3 など）との連携は次の段階。

- **ワーク原点**: 閉じた図形（外形）ごとに、図形を囲む四角の左上に自動で付く。座標は原点から右へ X+、下へ Y+。穴・切り欠きは外形の原点から測る
- **描く**: 指でなぞると、曲がった所で分けて水平・垂直の折れ線にする。角はグリッドに合わせる。既にある点の近くから描き始める・描き終えるとつながり、描き始めに戻ると閉じた図形になる
- **選ぶ**: 線・点・寸法の数字をタップして選ぶ（2 つまで）。右上の欄に数字を入れて寸法を決める
  - 線 1 本: 長さ、外形の原点からの距離
  - 点 1 つ: 外形の原点からの X・Y
  - 点と点: X 方向・Y 方向の距離
  - 点と線: 最短距離
  - 平行な線 2 本: 線の間の距離
  - 寸法の数字: 値を直す、寸法を消す
  - 寸法が決まると選択を解く
- 閉じた図形の内側を半透明で塗る。重ねた小さい図形は、内側に収まれば穴、辺をまたげば切り欠きとして、重なった範囲を抜く
- 外形の原点とつながって位置が決まった線は黒、まだ動く線は青で描く
- 線をつかむと平行に動かせる。両端につながった線は伸び縮みし、越えると向きが逆になる（入れた寸法は保つ）
- 点は指で動かせる（決まっている方向には動かない）。外形の左上の角をつかむと外形ごと動く
- 指2本で拡大縮小・移動、「全体表示」で元に戻す。元に戻す、削除、板の大きさの変更
- 新規作成のとき、プログラム番号と金型 T1〜T3 を決める。あとから「金型」で直せる
- 右側（縦向きでは下側）の区画に、点・線・寸法を原点からの座標で並べる（確認用）
- 名前を付けて保存・開く、JSON ファイルへの書き出し・読み込み、作業中の図面の自動保存
- オフラインで動く PWA（ホーム画面に追加して使う）

v0.4.0 までの四角穴（F3）はテスト用だったので消した。そのころ保存した図面を開くと、四角穴は読み込まれない。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` / `app.js` | アプリ本体（ビルド不要の素の HTML・JavaScript） |
| `geom.js` | 点・線・寸法のデータと、寸法から位置を決める処理 |
| `docs/sketch-spec.md` | 図形を描く部分の仕様 |
| `manifest.webmanifest` | PWA の設定（名前・アイコン） |
| `sw.js` | オフライン用の Service Worker |
| `icons/` | アイコン（`tools/make_icons.py` で作る） |
| `tools/make_icons.py` | アイコンを作る開発用の道具（Python 標準ライブラリのみ） |

## PC で動かす

```
python -m http.server 8765 --bind 127.0.0.1
```

ブラウザで http://localhost:8765 を開く。

## iPad で使う

公開先: https://username9982.github.io/setpress-cam/ （GitHub Pages。`main` ブランチに push すると数分で更新される）

Service Worker（オフライン動作）は **HTTPS** でしか動かないため、HTTPS の場所に置く必要がある。

1. iPad の Safari でページを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから開く（一度開けば、ネットが無くても動く）

保存した図面は、そのホーム画面のアプリの中に残る。Safari で開いたページとホーム画面のアプリでは保存場所が別になる。念のため「開く」→「ファイルに書き出す」でバックアップを取る。

## 更新するとき

中身を変えたら、版を上げる。

```
python tools/bump_version.py 0.2.1
```

`app.js` の `APP_VERSION`、`sw.js` の `CACHE_NAME`、`index.html` の `style.css?v=` / `geom.js?v=` / `app.js?v=` をまとめて書き換える。
URL に版を付けるのは、更新の直後に新しい `index.html` と古い `style.css`（キャッシュに残ったもの）が組み合わさって画面が崩れるのを防ぐため（v0.2.0 で、描く領域が消えた）。
Service Worker はネットにつながっていれば新しいファイルを取り、つながっていなければ前に取ったファイルで動く。
